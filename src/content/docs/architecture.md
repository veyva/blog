# Architecture

The site is built with Astro and Starlight, which provides the documentation layout, navigation, and theming layer.

## Core pieces

- Astro project and config
- Starlight integration
- Docs content collection
- Rapide theme plugin

## Why this structure

This layout is optimized for long-form technical reading, cross-linked notes, and navigable documentation pages.
